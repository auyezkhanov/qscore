# Qscore

Live-счёт и статистика футбола Казахстана в стиле FotMob: **Премьер-лига** и **Первая лига**.
Матчи по дням с live-обновлением, страница матча (ход игры, составы на схеме поля, статистика,
личные встречи, YouTube-трансляция), турнирные таблицы, календарь по турам, бомбардиры и ассистенты,
страницы команд и игроков (карьера, графики, подробная статистика), трансферы, новости,
поиск по командам и игрокам, избранные матчи с синхронизацией через аккаунт, RU/EN, светлая/тёмная тема.

В стиле FotMob также есть:
- рейтинги игроков 3–10 за каждый матч (и live), игрок матча, статистика игрока в матче;
- тренеры, судейская бригада, дисквалифицированные на матч, «где смотреть» и страница ТВ-трансляций;
- превью матча: форма, следующие матчи, автоматические «интересные факты», опрос «Кто победит?»;
- рейтинги игроков лиги по 16 показателям, статистика команд, архив сезонов с 2022 года;
- тренеры команды с процентом побед, сложность календаря, подписка на календарь (.ics);
- push-уведомления о голах, начале и конце матчей выбранных команд;
- игра «Прогнозист» с таблицей лидеров;
- рыночная стоимость с историей изменения (Transfermarkt).

Данные автоматически синхронизируются с официальным сайтом лиги [kffleague.kz](https://kffleague.kz);
суммы трансферов и рыночная стоимость игроков Премьер-лиги — с [Transfermarkt](https://www.transfermarkt.com).

## Стек

| Слой | Технологии |
|---|---|
| Frontend | React 18, TypeScript (strict), Vite, Tailwind CSS, TanStack Query, React Router, Recharts |
| Backend | Node.js 22, Express, TypeScript, Prisma, PostgreSQL 16, Zod |
| Инфраструктура | Docker Compose (postgres + backend + nginx со SPA и прокси `/api`) |

## Быстрый старт (Docker)

```bash
cp .env.example .env          # задайте JWT_SECRET
docker compose up -d --build
```

Откройте http://localhost:15173. При первом запуске бэкенд сам наполнит пустую базу с kffleague.kz
(≈3 минуты, на сайте в это время висит баннер «загружаем данные»).

Порты по умолчанию (`15432`, `14000`, `15173`) выбраны, чтобы не конфликтовать с другими проектами;
меняются в `.env`. База и API слушают только `127.0.0.1` — наружу смотрит лишь nginx (`15173`).
Пароль БД — `POSTGRES_PASSWORD` в `.env`.

Деплой в облако (Railway + Vercel) — см. [DEPLOY.md](DEPLOY.md).

## Локальная разработка

```bash
docker compose up -d postgres

cd backend
cp .env.example .env          # задайте JWT_SECRET
npm install
npx prisma migrate deploy
npm run dev                   # http://localhost:14000/api, первый проход синка стартует сам

cd ../frontend
npm install
npm run dev                   # http://localhost:15173 (проксирует /api на :14000)
```

Полезное:

```bash
# backend
npm run sync          # полный синк вручную
npm run sync:live     # один проход live-синка
npm run sync:tm       # обогащение данными Transfermarkt
npm test              # unit-тесты (vitest)
npm run typecheck

# frontend
npm run typecheck
npm run build
npm test              # unit-тесты (vitest)
npm run test:e2e      # E2E (Playwright) против запущенного стека, по умолчанию http://localhost:15173
```

E2E-тесты (`frontend/e2e`) проходят все вкладки: главная, матч (все табы, карточка игрока, голосование),
лига, команда, игрок, трансферы, новости, ТВ, прогнозы, избранное, вход/регистрация — на десктопе и
мобильном вьюпорте (Pixel 7). Тест падает при любой ошибке в консоли, необработанном исключении или
ответе API ≥ 400. Используется установленный Chrome; другой адрес — `E2E_BASE_URL=...`. Тестовые
аккаунты удаляются после прогона (`DELETE /api/auth/me`).

`SYNC_ENABLED=false` в `backend/.env` отключает фоновый синк (например, для офлайн-разработки).

### Синхронизация данных

- **Full sync** — при старте и раз в 6 часов: сезоны, таблицы, команды, составы, календарь, трансферы и
  детали сыгранных матчей (новых и за последние 3 дня). Только upsert — данные никогда не стираются целиком.
- **Live sync** — раз в минуту: счёт/статус/минута всех матчей, полные детали идущих и только что
  завершившихся матчей, таблица при изменении результата.
- Задачи не пересекаются даже между несколькими процессами: блокировка-аренда в БД (`SyncLock`, продлевается
  каждые 60 с). Во время длинного full sync live-обновление идущих матчей продолжается внутри него. Детали матча заменяются в одной транзакции, поэтому страница
  матча никогда не видит «полупустые» составы. Статус синка — `GET /api/health`.
- Английские имена игроков и команд берутся из источника (`lang=en`), для остального — транслитерация;
  названия стран — из ISO-кодов через `Intl`. Новости на английском — при заданном `DEEPL_API_KEY`.
- Статистика игроков хранится по сезонам и клубам (`PlayerSeasonStat`): переход игрока не «переносит» его
  голы в новый клуб, а бомбардиры лиги считаются только за выбранный сезон. Клуб игрока меняется только по
  заявке (roster), а не по строке статистики.
- Пустой ответ источника (таблица, заявка, страница TM) никогда не стирает данные — такой шаг пропускается.
- Матч перезаписывается только если что-то изменилось.
- Запросы к kffleague.kz и Transfermarkt идут через ограничители (параллельность + пауза), общие для синка
  и пользовательских запросов (карьера игрока, новости). Тяжёлые маршруты (`/players/:slug/career`,
  `/market-value`, `/media/avatar`) имеют лимит запросов по IP.

### Рейтинг игрока

Свой рейтинг 3.0–10.0 (`backend/src/lib/rating.ts`) считается из поматчевой статистики kffleague.kz.
Все стартуют с 6.0. Сильнее всего на оценку влияют голы (их вес зависит от позиции), ассисты, xG,
удары в створ, ключевые передачи и сейвы. Обводки, отборы, перехваты, единоборства и качество передач
дают поправки, сухой матч — бонус. Карточки, автоголы и незабитые пенальти снижают рейтинг, результат
матча добавляет небольшую поправку с учётом сыгранных минут. Игроки с выходом меньше чем на 10 минут
не оцениваются. Средний рейтинг по лиге — около 6.9, как у FotMob.

### Push-уведомления

Работают через Web Push (VAPID-ключи генерируются при первом запуске и хранятся в БД). Live-синк
определяет начало матча, голы, перерыв и финальный свисток и рассылает уведомления браузерам, которые
подписаны на одну из команд или на сам матч. В продакшене нужен HTTPS (на localhost работает без него).
Каждое событие отправляется ровно один раз (атомарная отметка в БД), из фоновой очереди с таймаутом,
и только на настоящие push-сервисы браузеров (FCM, Mozilla, Apple, Windows) — произвольные адреса отклоняются.

### Transfermarkt

Раз в сутки (`TM_SYNC_INTERVAL_HOURS`) задача `transfermarkt` загружает 17 страниц transfermarkt.com
(составы 16 клубов КПЛ и сводную страницу трансферов лиги) с паузой 2.5 с между запросами:

- **рыночная стоимость и срок контракта игроков.** Игроки сопоставляются в пределах клуба по дате рождения и имени;
  разные латинские написания учитываются. Совпадает около 97% игроков;
- **стоимость состава** клуба;
- **суммы трансферов** (сумма / аренда / платная аренда / бесплатно / возврат из аренды) и стоимость игрока
  на момент перехода. Для трансферов, которых нет на kffleague.kz, создаются отдельные записи (`source = "tm"`,
  в интерфейсе с пометкой «TM»).

Соответствие клубов TM и наших задано в `backend/src/integrations/transfermarkt/config.ts` — обновляйте его
при смене состава лиги. Если Transfermarkt недоступен или ограничивает запросы, остальные данные продолжают
обновляться, а повторная попытка будет через 3 часа. Отключается через `TM_SYNC_ENABLED=false`.

**Важно:** условия использования Transfermarkt запрещают автоматический сбор данных. Для личного или
фан-проекта это обычно терпят; перед публичным или коммерческим запуском эту часть стоит отключить
или получить разрешение. Источник указан в интерфейсе рядом с данными.

### API

Все GET-эндпоинты принимают `?lang=ru|en`. Ошибки: `{ "error": { "code", "message" } }`.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/health` | статус и состояние синка |
| GET | `/api/leagues` · `/api/leagues/:slug` | лиги |
| GET | `/api/leagues/:slug/standings` | таблица |
| GET | `/api/leagues/:slug/rounds` | матчи по турам + текущий тур |
| GET | `/api/leagues/:slug/top-players?stat=goals\|assists` | бомбардиры / ассистенты |
| GET | `/api/leagues/:slug/transfers?team=&position=&sort=recent|fee` | трансферы лиги (с суммами) |
| GET | `/api/matches?from=ISO&to=ISO` | матчи в интервале (локальный день клиента) |
| GET | `/api/matches/next-day?after=ISO&tzOffset=` | ближайший игровой день |
| GET | `/api/matches/:id` · `/api/matches/:id/h2h` | матч целиком · личные встречи |
| GET | `/api/teams?league=` · `/api/teams/:slug` | команды · команда |
| GET | `/api/teams/:slug/matches` · `/api/teams/:slug/transfers` | календарь · трансферы команды |
| GET | `/api/players/:slug` · `/stats` · `/career` | игрок · матчи и сравнение · карьера |
| GET | `/api/search?q=` | поиск команд и игроков |
| GET | `/api/matches/:id/preview` | форма, следующие матчи, интересные факты |
| GET/POST | `/api/matches/:id/votes` | опрос «Кто победит?» (гостям нужен заголовок `X-Voter-Id`) |
| GET | `/api/matches/tv?days=14` | расписание трансляций |
| GET | `/api/leagues/:slug/team-stats` | статистика команд |
| GET | `/api/leagues/:slug/seasons` · `/seasons/:year/standings` · `/seasons/:year/rounds` | архив сезонов |
| GET | `/api/players/:slug/market-value` | история рыночной стоимости |
| GET | `/api/calendar/teams/:slug.ics` · `/api/calendar/leagues/:slug.ics` | календари матчей |
| GET/PUT/DELETE | `/api/predictions/fixtures` · `/api/predictions/:matchId` · `/api/predictions/leaderboard` | «Прогнозист» |
| GET/POST/PUT/DELETE | `/api/push/public-key` · `/api/push/subscriptions[/follow]` | push-подписки |
| GET | `/api/news?league=&limit=` · `/api/news/:id` | новости |
| GET | `/api/media/avatar?url=` | фото игрока с прозрачным фоном (только kffleague.kz) |
| POST | `/api/auth/register` · `/api/auth/login`, GET `/api/auth/me` | аккаунт (JWT) |
| GET/PUT/DELETE | `/api/favorites[/:matchId]`, POST `/api/favorites/merge` | избранные матчи |

**Важно:** API kffleague.kz не документирован и может измениться без предупреждения.
